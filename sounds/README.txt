ব্রেক কই মামা? — অডিও ফোল্ডার
================================

ইঞ্জিনের শব্দ, হর্ন, ভিড়, ব্রেক, বিস্ফোরণ — সব ব্রাউজারেই লাইভ সিন্থেসাইজ হয়
(WebAudio), আর ডায়ালগের জন্য এই ফোল্ডারে এখন ১১টা রেকর্ড করা ক্লিপ জোড়া আছে।
ফাইলগুলো মুছে দিলেও গেম চুপ হবে না — তখন ডিভাইসের বাংলা ভয়েস
(speechSynthesis) লাইনগুলো পড়ে শোনাবে।

ক্লিপ দুই ভাগে ভাগ করা:

১) গেমের নিজের ক্লিপ
   horn_meme, khela_hobe, ki_pagolami, woww, kaj_thik_hoyni, brake, laugh,
   punch, dishum, mob_shout_1…3, woman_shout_1/2, hawker, sound_bomb_1/2 …
   (পুরো তালিকা manifest.json এ)

২) ফানি ডায়ালগ
   dipjol_1, dipjol_2, mosharraf_1, mosharraf_2, manna_1, manna_2
   — নাম যত খুশি বাড়াতে পারেন: dipjol_3, manna_7 …
     গেম নিজেই র‍্যান্ডম করে বাজাবে — একটা ক্লিপ শেষ হলে ২০–৪২ সেকেন্ড
     পর পরের লাইন (আর হর্ন/ধাক্কার শব্দ এলে ক্লিপ থেমে যায়)।

এখন যেসব ক্লিপ জোড়া আছে (manifest.json)
----------------------------------------
   hawker            ← assalamualaika_boro_vai.mp3        (হকারের ডাক)
   mob_shout_1       ← hisab-bujho-na-dudu-khao.mp3       (ভিড়ের গালি)
   mob_shout_2       ← engreji-marao.mp3
   mob_shout_3       ← patkhat-a-jabe-ajairapublick-…mp3
   dipjol_1          ← dipjol-aj-pothom-bar.mp3
   dipjol_2          ← dipjol-mandar-pola.mp3
   dipjol_3          ← kara-beya-kortasot.mp3
   mosharraf_1       ← ami-tension-kinchi.mp3
   mosharraf_2       ← tale-phone-rakhbena-…mp3
   manna_1           ← khankir-pola-by-manna.mp3
   manna_2           ← ami-tmr-premer-pagol.mp3

কোন ফাইল কোন স্লটে বসবে বদলাতে চাইলে শুধু manifest.json এ নাম অদলবদল
করুন — কোড ছুঁতে হবে না। ফাইল থাকলে গেম TTS ভয়েসের বদলে ক্লিপটাই বাজায়।

সাবটাইটেল (ঐচ্ছিক)
-------------------
   "dipjol_1": { "file": "dipjol-aj-pothom-bar.mp3", "text": "আজ প্রথমবার…" }
   text দিলে অটোর নিচের বাবলে ওই লেখাটাই দেখাবে — অর্থাৎ রেকর্ডিং যেটা
   বলে, স্ক্রিনে ঠিক সেটাই। text না দিলে গেমের নিজের লেখা লাইন দেখাবে।

ক্লিপ বাজলে কী হয়
------------------
   • ডায়ালগ ক্লিপ "পটভূমির আওয়াজ" হিসেবে বাজে — হর্ন, ধাক্কা, ভিড়ের
     চিৎকার বা বিস্ফোরণ এলে ক্লিপটা কেটে যায় (গেমপ্লের শব্দ অগ্রাধিকার পায়)।
   • প্রতিটা লাইনের পর বিরতি = ২০–৪২ সেকেন্ড + ক্লিপের নিজের দৈর্ঘ্য,
     তাই লম্বা রেকর্ডিং থাকলেও অটো একটানা বকবক করে না।
   • রাস্তার শব্দ ১৪ সেকেন্ডের বেশি চাপা থাকে না, ক্লিপ লম্বা হলেও গাড়ির
     ইঞ্জিনের আওয়াজ ফিরে আসে।

কীভাবে বসাবেন
-------------
১. ফাইলটা এই ফোল্ডারে রাখুন। নাম ইংরেজি ছোট হাতের অক্ষরে, স্পেস ছাড়া:
   dipjol_1.mp3, horn_meme.mp3 …
২. manifest.json খুলে ওই নামের পাশে ফাইলের নাম লিখুন:
   "dipjol_1": "dipjol_1.mp3",
৩. পেজ রিফ্রেশ। ব্যস।

সাপোর্টেড ফরম্যাট: mp3, ogg, m4a/webm (ব্রাউজার যেটা ডিকোড করতে পারে)।
সাইজ: সাউন্ড ইফেক্ট ০.৫–৩ সেকেন্ড, ডায়ালগ ৩–১০ সেকেন্ড (এই বিল্ডে
কয়েকটা ডায়ালগ ৯–২৪ সেকেন্ডও, তাও চলবে — বিরতি নিজেই বেড়ে যায়)।
পরামর্শ: mono, ৪৪.১ kHz, ৯৬ kbps — ফোনে দ্রুত লোড হবে।

দয়া করে খেয়াল রাখুন (গুরুত্বপূর্ণ)
----------------------------------
সিনেমা/নাটকের ডায়ালগ, গান বা ইউটিউব ক্লিপ ডাউনলোড করে এখানে রাখা মানে
কপিরাইট ভাঙা — ভিডিও কেটে অডিও বানালেও একই নিয়ম।
এই বিল্ডে যে ক্লিপগুলো আছে সেগুলো গেমের মালিক নিজে বসিয়েছেন, তাই সেগুলোর
অনুমতি/লাইসেন্স তাঁকে নিজেই যাচাই করে নিতে হবে। গেম পাবলিক করলে বা অন্য
কাউকে দিলে আগে ওই ফাইলগুলোর কথা ভাবুন — মুছে দিলেও গেম পুরো চলে।
যা নিরাপদ:
  • নিজে মুখে বলে রেকর্ড করা (আপনার সেরা ভিলেন ভয়েস!)
  • CC0 / Public Domain সাউন্ড লাইব্রেরি (freesound.org-এ CC0 ফিল্টার)
  • নিজের কেনা বা নিজের বানানো ক্লিপ
ডায়ালগ না দিলেও গেম ডিভাইসের বাংলা ভয়েসে (speechSynthesis) লাইনগুলো
পড়ে শোনাবে।

অফলাইনে
--------
সার্ভিস ওয়ার্কার শুধু গেম শেল (html/css/js) ক্যাশ করে, অডিও ফাইল নয়।
ইন্টারনেট ছাড়া খেললে TTS ভয়েস চলবে, ক্লিপ বাজবে না।
অফলাইনে ক্লিপও চাইলে ফাইলগুলো sw.js এর ASSETS তালিকায় যোগ করুন।
