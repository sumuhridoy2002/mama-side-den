## এক নজরে

আপনি একজন অটো ড্রাইভার। লক্ষ্য একটাই — **জাতীয় ক্ষতি** যত বেশি করা যায়।
গাড়ি, বাস, দোকান, ফুটপাতের হকার, রিকশা, পাবলিক — যাকে পান ধাক্কা দেন,
আর পুলিশ মামলা করলে "চা-পানি" দিয়ে মামলা ক্লোজ।

> গেমের নিজের ট্যাগলাইন: **“রাস্তা কি আপনার বাপের?”**
> উত্তর: না। তারপরও চালাতে হবে।

সব মিলিয়ে: ৩ডি ঢাকা, ২৩টা চেনা ল্যান্ডমার্ক, ট্রাফিক সিগন্যাল, ভিআইপি
গাড়িবহর, অবরোধ, ব্যাটারি-চার্জ, সংবাদপত্র, আর শেষে একটা পোস্টার যেখানে
আপনার নাম ওঠে।

## 🎮 যা যা আছে

### 🛣 রাস্তা ও গেমপ্লে

- **জাতীয় ক্ষতি কাউন্টার** — ধাক্কা মানেই টাকা। পরপর ধাক্কায় **×২ কম্বো**।
- **বাস-ট্রাক ছুঁলেই শেষ** — নিচে লাল আলো মানে “দূরে থাকেন”।
- **চার্জ শেষ হলে গাড়ি থেমে যায়** — হলুদ দাগে গেলে চার্জ, মিনিম্যাপে
  চার্জিং পয়েন্ট আর দিক-তীর।
- **টান (Boost)** — বেশি গতি, বেশি চার্জ খরচ, বেশি ক্ষতি।
- **হর্ন আর শব্দবোমা** — মানুষ লাফায়, ভিড় জমে, ধাওয়া শুরু হয়।
- **পাবলিকের ধাওয়া** — ধরিয়ে গেলে ধোলাই; তার আগে পালান।
- **সানডে মানডে ক্লোজ (ঘুষ-অর্থনীতি)** — ক্ষতির ২০% চা-পানিতে মিটে যায়,
  পরেরবার রেট ১০% বাড়ে, ভিআইপি হলে ফ্রি। রসিদ কেউ দেয় না।
- **ভিআইপি গাড়িবহর ও অবরোধ** — HUD-এ তীর আর দূরত্ব; ভিআইপিতে ধাক্কা
  দিলে বড় স্কোর, আর পত্রিকায় বড় শিরোনাম।

### 🗺 ঢাকা ম্যাপ

- **২৩টা ল্যান্ডমার্ক, হাতে বানানো**: সোহরাওয়ার্দী উদ্যান, অপরাজেয় বাংলা,
  শহীদ মিনার, কার্জন হল, বায়তুল মোকাররম, কমলাপুর, হাতিরঝিল, লালবাগ কেল্লা,
  আহসান মঞ্জিল, জাতীয় সংসদ, নভোথিয়েটার, স্টেডিয়াম, বিমানবন্দর,
  গুলশান লেক, জাতীয় স্মৃতিসৌধ, মিরপুর ১০ মেট্রো …
- **শুরু বেছে নিন**: শাহবাগ / গুলিস্তান / মিরপুর ১০ / উত্তরা / যাত্রাবাড়ী,
  নাহলে “প্রতি রানে নতুন জায়গা”।
- **শহরের বাইরের নামও আছে**: টঙ্গী, গাজীপুর চৌরাস্তা, কেরানীগঞ্জ, শ্যামপুর,
  সাভার, নারায়ণগঞ্জ রোড — ব্লক-ব্লক নাম বদলায়, তাই মনে হয় ঢাকা বড়।
- **দূরের স্কাইলাইন + কুয়াশা** — চোখের সামনে শহর শেষ হয় না, মিলিয়ে যায়।
- **দিন-রাত**: সকাল, বিকেল, গোধূলি, রাত — লাইটপোস্ট জ্বলে, রং বদলায়।

### 🚦 ট্রাফিক আর মানুষ

- ১০ রকম গাড়ি: কার, মাইক্রো, এসইউভি, পুলিশ, বাস, ট্রাক, লেগুনা, সিএনজি,
  বাইক, অটো — প্রত্যেকের আলাদা ইঞ্জিন আওয়াজ।
- **ট্রাফিক সিগন্যাল** (সবুজ/অ্যাম্বার/লাল), লেন-ভাঙা চালক, রাস্তা আটকে রাখা।
- **হকার, ফুটপাতের দোকান, ভ্রাম্যমাণ বিক্রেতা** — ধাক্কা দিলে পত্রিকায় খবর।
- **ভিড়** — শব্দবোমা ফাটালে কয়েকশো মানুষ একসাথে লাফায়।

### ⚡ অডিও (লাইভ ইঞ্জিন + নিজের ডায়ালগ)

- ইঞ্জিন, হর্ন, ব্রেক, কাঁচের শব্দ, ভিড়ের গুঞ্জন, পাখি, রাতের দূরের কোলাহল —
  সব **WebAudio-তে লাইভ বানানো**, কোনো ফাইল লাগে না।
- **ফানি ডায়ালগ** — ভিলেন, অফিস-ক্লান্ত মামা আর হিরো ভাইবের লাইন। `sounds/`
  ফোল্ডারে রেকর্ডিং থাকলে সেটাই বাজে, না থাকলে ডিভাইসের বাংলা ভয়েস
  (speechSynthesis) পড়ে শোনায়। স্ক্রিনেও সাবটাইটেল আসে — রেকর্ডিংয়ের ক্ষেত্রে
  `manifest.json`-এ দেওয়া লেখাটাই।
- ক্লিপগুলো "পটভূমির আওয়াজ": হর্ন, ধাক্কা বা বিস্ফোরণ এলে ডায়ালগ থেমে যায়,
  আর একটা লাইনের পরের লাইন আসে ২০–৪২ সেকেন্ড **+ ক্লিপের নিজের দৈর্ঘ্য** পরে।
- নিজের ক্লিপ বসানোর নিয়ম নিচের **🔊 নিজের অডিও বসাবেন কীভাবে** অংশে।

### 📊 স্কোর, পত্রিকা আর শেয়ার

- **“দৈনিক যানজট”** — রান শেষে সত্যিকারের খবরের কায়দায় রিপোর্ট: আপনার
  ঘটনার শিরোনাম, টেবিল-ভিত্তিক পরিসংখ্যান, একটা কোট, আর “তিন সদস্যের
  তদন্ত কমিটি” (কমিটির রিপোর্টও আসে না)।
- **মোস্ট ওয়ান্টেড** — সাপ্তাহিক তালিকায় র‍্যাংক, পোস্টারে নিজের নাম দেওয়ার সুযোগ।
- **নিজের রেকর্ড** — এই ব্রাউজারের শেষ ৩০টা অভিযান, ৭ দিনের ট্যাব,
  রিপোর্ট ডাউনলোড।
- **শেয়ার** — স্ক্রিনশট ছবি, বা গেমপ্লে ভিডিও ক্লিপ (MediaRecorder),
  ফেসবুক/ইনস্টাগ্রামে দেওয়ার বোতাম।

### ⚙️ সেটিংস (মোবাইল-ফার্স্ট)

গ্রাফিক্স (স্বয়ংক্রিয়/উচ্চ/ব্যালান্সড/লো/সর্বনিম্ন), ফ্রেম রেট ৩০ বা ৬০,
দিনের সময়, শুরুর জায়গা, শব্দের মাত্রা, কম অ্যানিমেশন, বড় টাচ বোতাম,
FPS দেখা, বাংলা ভয়েস অন/অফ, আর **ফানি ডায়ালগ** আলাদা করে বন্ধ করার সুইচ।

### 📱 ইনস্টল ও অফলাইন

PWA — হোম স্ক্রিনে বসিয়ে ফুলস্ক্রিনে খেলবেন। সার্ভিস ওয়ার্কার গেম শেল
ক্যাশ করে, তাই নেট ছাড়াও লোড হয়। (নতুন বিল্ড এলে নিজেই একবার রিলোড নেয়।)

## 🕹 কীভাবে খেলবেন

| কী | কাজ |
| --- | --- |
| `W` / `↑` | চালান |
| `S` / `↓` | ব্রেক |
| `A` `D` / `←` `→` | ঘোরান |
| `Shift` / `Space` | টান (বুস্ট) |
| `H` | হর্ন |
| `B` | শব্দবোমা |
| `C` | ক্যামেরা বদলান (পেছন → কাছে → পাশ → ওপর → সামনে) |
| `M` | শব্দ চালু/বন্ধ |
| `Esc` | চা-বিরতি (পজ) |

মোবাইলে ডান দিকে গ্যাস/ব্রেক, বাঁয়ে হর্ন-বোমা আর বাঁক — আঙুলের জন্যই বানানো।

> কোনো কিবোর্ডে `↑ + ← + Space` একসাথে ধরা যায় না। তখন ডান `Shift`
> চাপুন, অথবা `↑` ছেড়ে শুধু `Space` ধরুন — টান দিলে অটো এমনিই চলে।

## 🚀 নিজের কম্পিউটারে চালাবেন কীভাবে

```bash
# যেকোনো একটা:
python -m http.server 8080        # তারপর http://localhost:8080
npx serve .                       # নাহলে এটা
```

লারাগন ব্যবহার করলে ফোল্ডারটা `c:\laragon\www\` এ থাকে, ব্রাউজারে
`http://mama-side-den.test` খুলুন।

দুটো কথা মনে রাখবেন:

- `file://` দিয়ে খুললে গেম চলবে, কিন্তু **সার্ভিস ওয়ার্কার/ইনস্টল কাজ করবে না**
  (ব্রাউজারের নিয়ম)। অফলাইন চাইলে `localhost` বা `https` লাগবে।
- **মোস্ট ওয়ান্টেড তালিকা** `api/board` থেকে আসে। লোকালি সেই `api/` না থাকলে
  গেম ভাঙবে না — শুধু লিখে দেবে “যাচাই করা গেল না, এই রানটা তালিকায় উঠল না”।
  বাকি সব অফলাইনেই চলে।

## 📁 ফাইল স্ট্রাকচার

```
mama-side-den/
├── index.html            # পুরো UI: HUD, মেনু, পত্রিকা, সেটিংস
├── style.css             # সব স্টাইল (এক ফাইলে, ইচ্ছা করেই)
├── script.js             # গেম + Three.js + অডিও ইঞ্জিন + UI লজিক
├── sw.js                 # সার্ভিস ওয়ার্কার (শুধু গেম শেল ক্যাশ করে)
├── manifest.webmanifest  # PWA: নাম, আইকন, রং
├── icon-192.png / icon-512.png
├── .htaccess             # ক্যাশ/কম্প্রেশন হেডার
├── sounds/               # ডায়ালগের রেকর্ডিং (না থাকলেও গেম চলে)
│   ├── manifest.json     # কোন শব্দ কোন ফাইলে (+ সাবটাইটেল)
│   └── *.mp3             # এই বিল্ডে ১১টা ক্লিপ
└── README.md             # এই ফাইলটাই — সাউন্ডের নিয়মও এখানেই
```

কোনো বিল্ড নেই, বান্ডলার নেই, `node_modules` নেই। ফাইল এডিট করলেন → রিফ্রেশ
→ শেষ। (`sw.js`-এর `CACHE` ভার্সন বদলাতে ভুলবেন না, নাহলে পুরোনো ক্যাশ
আটকে থাকবে।)

### নতুন ক্লিপ বসাবেন

1. ফাইলটা `sounds/` এ রাখুন — নাম ছোট হাতের ইংরেজি, স্পেস ছাড়া
   (`dipjol_4.mp3`, `horn_meme.mp3`)।
2. `sounds/manifest.json` এ নাম লিখুন; সাবটাইটেলও চাইলে `text` সহ:
   ```json
   {
     "horn_meme": "horn.mp3",
     "dipjol_4": { "file": "dipjol_4.mp3", "text": "যা বলা হচ্ছে" }
   }
   ```
3. রিফ্রেশ। ফাইল থাকলে রেকর্ডিং বাজবে, না থাকলে আগের মতো সিন্থ/ভয়েস চলবে।

স্লটের নাম যত খুশি বাড়াতে পারেন — `dipjol_4`, `manna_7` … গেম নিজেই র‍্যান্ডম
করে বাজায়। গেমের নিজের স্লটগুলোর পুরো তালিকা: `horn_meme`, `khela_hobe`,
`ki_pagolami`, `woww`, `kaj_thik_hoyni`, `yooo`, `brake`, `laugh`, `punch`,
`dishum`, `cartoon_impact`, `crash_meme`, `masud`, `no_need_explanation`,
`rag_korla`, `sound_bomb_1/2`, `mob_shout_1/2/3`, `woman_shout_1/2`,
`woman_protishodh`, `woman_thappor`, `hawker`, `hawker_2`।

### ক্লিপ বাজলে কী হয়

- ডায়ালগ ক্লিপ "পটভূমির আওয়াজ" — হর্ন, ধাক্কা, ভিড়ের চিৎকার বা বিস্ফোরণ এলে
  ক্লিপটা কেটে যায় (গেমপ্লের শব্দের অগ্রাধিকার বেশি)।
- প্রতিটা লাইনের পরের বিরতি = **২০–৪২ সেকেন্ড + ক্লিপের দৈর্ঘ্য**, তাই লম্বা
  রেকর্ডিং থাকলেও অটো একটানা বকবক করে না।
- রাস্তার আওয়াজ **১৪ সেকেন্ডের বেশি** চাপা থাকে না — ক্লিপ লম্বা হলেও ইঞ্জিনের
  শব্দ ফিরে আসে।
- রেকর্ডিং না থাকলে (বা `sounds/` ফোল্ডার মুছে দিলে) পুরো গেম আগের মতোই চলে,
  শুধু ডায়ালগ ডিভাইসের বাংলা ভয়েসে পড়া হয়।

### ফরম্যাট, সাইজ, অফলাইন

- ব্রাউজার যেটা ডিকোড করে: **mp3, ogg, m4a/webm**।
- সাউন্ড ইফেক্ট ০.৫–৩ সেকেন্ড, ডায়ালগ ৩–১০ সেকেন্ড (এই বিল্ডে কয়েকটা
  ৯–২৪ সেকেন্ডও আছে — তাও চলবে, বিরতি নিজেই বেড়ে যায়)।
- পরামর্শ: **mono, ৪৪.১ kHz, ৯৬ kbps** — ফোনে দ্রুত লোড হবে।
- সার্ভিস ওয়ার্কার শুধু গেম শেল (html/css/js) ক্যাশ করে, অডিও ফাইল নয়।
  ইন্টারনেট ছাড়া খেললে ভয়েস চলবে, ক্লিপ বাজবে না — অফলাইনে ক্লিপও চাইলে
  ফাইলগুলো `sw.js`-এর `ASSETS` তালিকায় যোগ করুন।

> ⚠️ **কপিরাইট প্রসঙ্গ:** সিনেমা/নাটকের ডায়ালগ, গান বা ইউটিউব ক্লিপ কেটে এখানে
> রাখা কপিরাইট লঙ্ঘন। ডায়ালগের **লেখা লাইনগুলো** এই গেমের জন্যই নতুন করে লেখা,
> ওই তিনজনের *স্টাইলে* ট্রিবিউট — কিন্তু `sounds/`-এ যে **রেকর্ডিংগুলো** জোড়া
> আছে সেগুলো মালিক নিজে বসিয়েছেন, তাই সেগুলোর অনুমতি/লাইসেন্স তিনিই যাচাই করে
> নেবেন (পাবলিক করার আগে বা অন্য কাউকে দেওয়ার আগে)। ফাইলগুলো মুছে দিলেও গেম
> পুরো চলে। নিরাপদ পথ: নিজে মুখে বলে রেকর্ড করা, CC0/পাবলিক ডোমেইন লাইব্রেরি,
> বা নিজের কেনা ক্লিপ।

## 🤫 লুকানো হ্যাক (সাপোর্ট/কৌতূহলীদের জন্য)

URL-এ যোগ করলেই কাজ করে:

| কি যোগ করবেন | কী হবে |
| --- | --- |
| `?start=shahbag` | শাহবাগ, গুলিস্তান, মিরপুর ১০, উত্তরা, যাত্রাবাড়ী থেকে শুরু |
| `?time=night` | সকাল/বিকেল/গোধূলি/রাত পাকাপাকি |
| `?quality=0` | গ্রাফিক্স টিয়ার (0 উচ্চ … 3 সর্বনিম্ন) হাতে ঠিক করা |
| `?fps` | স্ক্রিনে FPS |
| `?k=5000&at=rafi` | বন্ধুর স্কোর ভাঙার চ্যালেঞ্জ লিংক |
| `?debug` | ডিবাগ হুক (শুধু লোকালহোস্টে/webdriver-এ খোলে) |

কনসোল থেকে:

```js
__funny.say('dipjol')   // ভিলেনের একটা লাইন এখনই শোনান
__funny.once()          // গেমের নিজের পথে একবার (মিউট/পজ গোনায়)
__funny.lines           // সব ডায়ালগ, দরকারে এডিট করার জন্য
__funny.clips()         // কোন রেকর্ডিং লোড হয়েছে
__audio.play('horn_meme')       // একটা ক্লিপ সরাসরি বাজিয়ে দেখুন
__voice.list()          // ডিভাইসে কী কী ভয়েস আছে
__voice.latin('ব্রেক কই মামা')  // বাংলা ভয়েস না থাকলে যে উচ্চারণ হয়
```

## 🧯 কিছু গোলমাল হলে

**সাদা স্ক্রিন / লোড হচ্ছে… আটকে আছে** → কনসোলে কী লেখা আছে দেখুন।
সন্দেহ হলে `DevTools → Application → Clear storage` দিয়ে ক্যাশ মুছুন, তারপর
আবার খুলুন। অনেক সময় দোষটা পুরোনো সার্ভিস ওয়ার্কারের।

**ফোন গরম / ফ্রেম ড্রপ** → সেটিংস → গ্রাফিক্স **সর্বনিম্ন**, ফ্রেম রেট **৩০**,
“কম অ্যানিমেশন” চালু। অটো মোডও নিজে নিজে কমিয়ে নেয়।

**শব্দ নেই** → `M` চেপে আনমিউট, সেটিংসে ভলিউম, আর মোবাইলে সাইলেন্ট সুইচ।
ব্রাউজার প্রথম ট্যাপের আগে অডিও চালায় না — “রাস্তায় নামুন” চাপার পরেই শব্দ।

**ডায়ালগ পড়ছে না** → সেটিংসে “বাংলা ডিভাইস ভয়েস” চেক করা আছে কি না দেখুন।
ফোনে বাংলা TTS না থাকলে ইংরেজি ভয়েসে উচ্চারণ শোনাবে — অদ্ভুত শোনাবে, কিন্তু
বুঝতে পারবেন। এটাই মজা।

**অফলাইনে পুরোনো ভার্সন** → `sw.js` এ `CACHE` এর নাম বদলে দিন
(`final-20261104` → পরের তারিখ)। নতুন ক্যাশ, নতুন কোড।

**মোস্ট ওয়ান্টেডে নাম উঠছে না** → ওই তালিকা `api/board` লাগে; লাইভ সাইটে
(`brakeKoiMama.com`) কাজ করে, লোকাল কপিতে না।
